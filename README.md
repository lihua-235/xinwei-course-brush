芯位蜜线（beeline-ai.com）课程视频自动播放工具。脱离浏览器，纯 Python 模拟 HTTP 上报，按 1 倍速正常播放的节奏提交学习进度。

## 功能特性

- 🔐 账号密码登录，token 自动保存，下次免登录
- 📚 自动拉取课程列表、章节、视频
- ▶️ 按「步长 30 秒 + 间隔 30 秒」上报进度，等效 1 倍速播放
- 🔄 断点续学：从服务端记录的 `studyTime` 继续，已完成的自动跳过
- ♻️ Token 失效（401）自动重新登录并重试
- 🖥️ 一键启动脚本，自动查找 Python、自动安装依赖

## 环境要求

- Windows 系统
- Python 3.8 或更高版本（安装时勾选 `Add Python to PATH`）
- 依赖：`requests`、`brotli`（启动脚本会自动安装）

## 安装

```bash
git clone https://github.com/lihua-235/xinwei-course-brush.git
cd xinwei-course-brush
pip install -r requirements.txt
```

> 也可以直接在仓库页面点 **Code → Download ZIP** 下载压缩包，解压后双击 `启动.bat` 使用，无需命令行。

## 使用

### 方式一：一键启动（推荐）

双击 `启动.bat`，首次运行会自动安装依赖，然后按提示操作即可。

### 方式二：命令行

```bash
python main.py
```

首次运行流程：

1. 输入账号、密码（保存到 `config.json`，下次免输）
2. 程序列出你的全部课程，输入序号选择
3. 显示课程进度，输入 `y` 开始刷课

之后再运行就只需双击 + 输入 `y`。

### 命令行参数

| 参数 | 说明 |
|---|---|
| `--list` | 仅列出所有课程，不刷课 |
| `--show` | 仅显示当前进度 |
| `--interval N` | 上报间隔（秒），默认 30 |
| `--target "标题"` | 只刷指定标题的视频（可多个） |
| `--debug` | 打印详细 HTTP 发包日志 |
| `--no-random` | 禁用随机延迟 |

示例：

```bash
python main.py --list
python main.py --show
python main.py --target "1.1 操作系统初步认识"
```

## 工作原理

1. **登录**：`POST /api/xinwei-auth/oauth2/token`，密码 MD5 加密，`client_id=xinwei`，获取 Bearer token
2. **取课程树**：`getChapterData` 返回三层结构 —— 章（`type=0`）→ 节（`type=1`）→ 资源（`type=2`），真正的视频是 `type=2` 且带 `totalTime` 的记录（PDF 课件 `totalTime=0`，不计入完成度）
3. **切换视频**：`enterClass` → `getSingleChapterData/{itemId}`
4. **上报进度**：`videoLearnProcessReport`，每次提交 `startPosition → endPosition` 共 30 秒
5. **完成确认**：`recordLearning` → `getExamineData` → 末尾补一次上报

## 时间预估

刷课是 1 倍速模拟，**耗时约等于课程视频总时长**。一门 60 个视频的课通常需要 10–15 小时，期间电脑不能睡眠、窗口不能关闭。

中途关闭没有关系，下次运行会自动跳过已完成的、从断点继续。

## 常见问题

**提示「验证码不能为空 / 请输入正确的验证码」**
平台触发了防暴力破解保护。不要连续重试，等待 30 分钟以上再运行。

**提示「请求过于频繁，请稍后再试」**
登录频率超限，等几分钟再试（程序内置自动等待重试）。

**刷到一半突然全部 `401 Unauthorized`**
同一账号在其他地方（网页端、手机 App、另一台电脑）登录了，把这里的会话顶掉了。平台是单会话机制，程序会自动重新登录恢复，但**刷课期间请勿在其他地方登录同一账号**。

**进度不动或全部失败**
可能是平台接口改版，请查看 `brush_course.log` 中的错误信息。

## 项目结构

| 文件 | 作用 |
|---|---|
| `启动.bat` | 一键启动（自动找 Python、自动装依赖） |
| `main.py` | 入口：命令行参数、交互选择、流程编排 |
| `login.py` | 登录认证、token 管理、会话持久化 |
| `auto_player.py` | 核心：进度上报、视频切换、断点续学、401 自动重登 |
| `course_fetcher.py` | 拉取课程列表、解析章节树 |
| `config.json` | 运行后自动生成，保存账号与选课结果（**明文，切勿提交**） |
| `session.json` | 运行后自动生成，保存登录凭证（**切勿提交**） |
| `brush_course.log` | 运行日志 |

> `config.json`、`session.json`、`*.log`、`__pycache__/` 已在 `.gitignore` 中排除。
